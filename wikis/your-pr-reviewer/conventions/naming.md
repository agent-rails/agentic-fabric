# Naming Conventions

## TypeScript/JavaScript
- Files & dirs: kebab-case (`transaction-signer.ts`)
- Components: kebab-case (`user-avatar.tsx`)
- Constants: SCREAMING_SNAKE_CASE (`MAX_TOKENS_IN_ESCROW`)
- Booleans: `is`, `has`, `should` prefix (`isVerified`)
- Event handlers: `handle` prefix (`handleClick`)

## Python
- Functions: verbs, snake_case
- Variables: clear nouns, snake_case
- No abbreviations

## General
- Functions = verbs, variables = nouns
- Intentionally unused variables: underscore prefix allowed
